# ASCII Table Printer
Um programa simples que imprime a tabela ASCII com opção de pausa.

## O que aprendi:
- Manipulação de caracteres
- Uso de unsigned char
- Limpeza do buffer do scanf
- Controle de fluxo com break/continue
